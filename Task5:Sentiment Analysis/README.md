# Task 5: Sentiment Analysis Chatbot

This project integrates sentiment analysis into a chatbot to detect positive, negative, and neutral emotional tones in user messages. Based on the identified sentiment, the chatbot adjusts its response style to provide supportive, encouraging, or informative replies that better match the user’s emotional state. The expected outcome is improved user experience and higher satisfaction through emotionally aware and contextually sensitive interactions.

Simple rule-based sentiment stub and an optional Streamlit GUI. Replace with transformer-based classifier for production.
