# Task 1: Dynamic Knowledge Expansion

This task contains a minimal scaffold for adding new documents to a knowledge base and a stubbed query function. Replace the stubbed retrieval with embeddings + vector DB (FAISS, Milvus) when running locally.
This project proposes a system for dynamically expanding a chatbot's knowledge base by periodically updating a vector database with new information from specified sources. The system utilizes natural language processing (NLP) techniques and vector databases to efficiently store and retrieve information, enabling the chatbot to automatically incorporate new knowledge into its responses over time. The proposed system aims to improve the chatbot's accuracy, relevance, and overall user experience
